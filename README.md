## 📌 About this application

The weather-glass-dashboard brings local weather data to your desktop with a clean, glass-like design. This interface uses the latest web design trends to display temperature, wind speed, and humidity. It runs as a standalone tool on your computer. You do not need to install complex software, coding environments, or build tools to use it. It functions as a simple, elegant window into your local weather conditions.

## 💻 System requirements

This application works on any modern version of Microsoft Windows. Ensure your computer meets these basic standards:

*   Windows 10 or Windows 11 operating system.
*   A standard web browser like Microsoft Edge, Google Chrome, or Mozilla Firefox.
*   At least 200 megabytes of free storage space.
*   An active internet connection to retrieve live weather data.
*   Four gigabytes of system memory.

## 🛠️ Features

The dashboard includes several components to help you track current weather patterns.

*   **Current Temperature Display:** Shows the exact heat level for your chosen location in large, easy-to-read numbers.
*   **Weather Condition Icons:** Visual cues identify clear skies, rain, clouds, or snow conditions instantly.
*   **Glassmorphism Interface:** The design uses semi-transparent backgrounds to create a depth effect that matches modern desktop aesthetics.
*   **Humidity Metrics:** Numerical trackers display the current moisture levels in the air.
*   **Wind Speed:** A dedicated gauge tracks how fast the wind blows in your area.
*   **Location Search:** A simple text box allows you to change the city or town to see weather updates for different regions.

## 🔍 Troubleshooting common issues

If you encounter trouble, use these solutions to fix the most common issues.

**The dashboard does not show weather data.**
Check your internet connection. The application requires a live connection to fetch data from weather servers. Try refreshing your browser page if the information does not load after one minute.

**The file will not open.**
Ensure you extracted the files from the compressed zip folder. Windows cannot run the application correctly if the files remain inside the zipped container. Right-click the folder and select Extract All to move the files to a usable state.

**Text or icons look small.**
Use the zoom feature in your browser to adjust the size. Press the Control key and the Plus (+) key on your keyboard to increase the size. Press Control and the Minus (-) key to decrease it.

**The interface looks plain.**
Make sure you keep all files within the same folder. The dashboard needs the styling files included in your download to render the glass effects correctly. If you move the index.html file without its supporting folders, the visual style will not load.
